# Job Market Analysis

## Project Overview
This project analyzes job market data to identify trends in job roles, salaries, locations, experience levels, and other job-related factors.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI
- Jupyter Notebook

## Project Workflow
1. Data Understanding
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Power BI Dashboard

## Project Files
- `data_understanding.ipynb` – Understanding the dataset
- `data_cleaning.ipynb` – Data cleaning and preprocessing
- `exp_data_analysis.ipynb` – Exploratory data analysis
- `dashbord.pbix` – Interactive Power BI dashboard

## Dashboard
The Power BI dashboard provides insights into job market trends, salaries, job roles, experience levels, and other relevant metrics.

## Dataset
The project uses job market data for analysis and visualization.
